## How to Update This File

At the end of every coaching session, update **only the sections that changed**:

- **Snapshot:** Day number, last weight (if weigh-in happened), protein status, gym sessions done, diet mode
- **Kitchen Stock:** Deplete used items (estimate remaining), add new items from orders, note confirms
- **Standing Rule Overrides:** Add any new rule with date, mark old ones if revoked
- **Pending Decisions:** Mark `✅ Resolved` or remove resolved items, add new pending items
- **Medical Log:** Add new incidents, update resolved items
- **Grocery Orders:** Add new orders, mark as delivered when confirmed

> **Rule for updates:** Be specific with quantities where known. Use ⚠️ for uncertain. Use ❌ for depleted. Do not write paragraphs — this file is a structured lookup table, not a journal.
